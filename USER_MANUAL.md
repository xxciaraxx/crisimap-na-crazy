# CRISIMAP User Manual

## MSWDO Head / Supervisor
- View dashboard analytics and recent activity
- Review all beneficiary records and export reports
- Manage users and settings

## AICS Focal Person
- Register and update beneficiary records
- Use the map to review beneficiary locations
- Generate PDF and Excel reports

## Social Welfare Officer
- Encode new beneficiaries
- Add address details and coordinates
- View records for assigned barangays

## Technical Expert
- Maintain user accounts and system settings
- Review audit logs and manage lookup tables
